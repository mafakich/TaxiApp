## 📖 Описание проекта

**TaxiApp** — это десктопное приложение для диспетчеров службы такси, которое позволяет:
- Регистрировать и управлять заказами
- Вести базу клиентов и водителей
- Отслеживать статусы поездок
- Формировать историю выполненных заказов
- Анализировать статистику работы

### Целевая аудитория
- Диспетчеры такси
- Администраторы службы такси
- Менеджеры по работе с клиентами

## ⚙️ Функциональные возможности

### Управление заказами
- ✅ Создание новых заказов

- ✅ История поездок клиента
- ✅ Контактная информация

### Отчётность
- ✅ Статистика по заказам
- ✅ Фильтрация по датам и статусам

## 📥 Установка и запуск

### Системные требования
- Windows 10/11
- .NET 10 Runtime или SDK
- 100 MB свободного места

### Инструкция по установке

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/TaxiApp.git
   cd TaxiApp
2. **Откройте решение в Visual Studio**
   ```bash
   TaxiApp.sln
3. **Установите NuGet пакеты**
   ```bash
   dotnet restore
4. **Соберите проект**
   ```bash
   dotnet build
5. **Запустите приложение**
   ```bash
   dotnet run --project TaxiApp

## 🗄 База данных
Сущности
Order (Заказы)

    Id - уникальный идентификатор
    OrderDate - дата и время заказа
    PickupAddress - адрес подачи
    DropoffAddress - адрес назначения
    Price - стоимость
    Status - статус заказа
    ClientId - ссылка на клиента
    DriverId - ссылка на водителя

Client (Клиенты)

    Id - уникальный идентификатор
    Name - ФИО
    Phone - телефон
    Email - электронная почта

Driver (Водители)

    Id - уникальный идентификатор
    FullName - ФИО
    Phone - телефон
    LicenseNumber - номер прав
    VehicleId - ссылка на автомобиль

Vehicle (Автомобили)

    Id - уникальный идентификатор
    Model - модель
    LicensePlate - гос. номер
    Color - цвет

## 💻 Использование
Создание заказа

    Нажмите кнопку "➕ Новый заказ"
    Выберите клиента или добавьте нового
    Укажите адреса подачи и назначения
    Назначьте водителя (опционально)
    Укажите стоимость
    Нажмите "✅ Создать заказ"

Поиск заказов

    Введите текст в поле поиска
    Выберите статус из выпадающего списка
    Нажмите "🔄 Обновить"

Просмотр истории

    Нажмите кнопку "📋 История"
    Выберите период
    Нажмите "🔍 Применить фильтр"
    Просмотрите статистику
