## 📖 Описание проекта

**TaxiApp** — это десктопное приложение для диспетчеров службы такси, которое позволяет:
- Регистрировать и управлять заказами
- Вести базу клиентов и водителей
- Отслеживать статусы поездок
- Формировать историю выполненных заказов
- Анализировать статистику работы

### Целевая аудитория
- Диспетчеры такси
- Администраторы службы такси
- Менеджеры по работе с клиентами

## ⚙️ Функциональные возможности

### Управление заказами
- ✅ Создание новых заказов
- ✅ Назначение водителей
- ✅ Отслеживание статуса (В ожидании, В пути, Завершён, Отменён)
- ✅ Поиск и фильтрация заказов
- ✅ Просмотр истории заказов

### Управление водителями
- ✅ База данных водителей
- ✅ Информация о транспортных средствах
- ✅ Привязка автомобиля к водителю

### Работа с клиентами
- ✅ Регистрация клиентов
- ✅ История поездок клиента
- ✅ Контактная информация

### Отчётность
- ✅ Статистика по заказам
- ✅ Фильтрация по датам и статусам
- ✅ Подсчёт выручки

## 🛠 Технологии

### Backend
- **.NET 10** - фреймворк
- **Entity Framework Core** - ORM
- **SQLite** - база данных

### Frontend
- **WPF (Windows Presentation Foundation)** - UI фреймворк
- **XAML** - разметка интерфейса

### Архитектура
- **MVP/MVVM** - паттерны проектирования
- **Repository Pattern** - работа с данными
- **Dependency Injection** - внедрение зависимостей

## 📥 Установка и запуск

### Системные требования
- Windows 10/11
- .NET 10 Runtime или SDK
- 100 MB свободного места

### Инструкция по установке

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/yourusername/TaxiApp.git
   cd TaxiApp
2. **Откройте решение в Visual Studio**
   ```bash
   TaxiApp.sln
3. **Установите NuGet пакеты**
   ```bash
   dotnet restore
4. **Соберите проект**
   ```bash
   dotnet build
5. **Запустите приложение**
   ```bash
   dotnet run --project TaxiApp
